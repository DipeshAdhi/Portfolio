# Portfolio — Dipesh Raj Adhikari

Plain HTML/CSS/JS. No build step.

- `index.html` — all page copy
- `styles.css` — colours are at the top in `:root`
- `script.js` — the backlog cards (edit the `cards` list to move a card between columns) and the experience data (`roles`, `education`)

## Put it online (GitHub Pages)

1. Create a new public repo named exactly `DipeshAdhi.github.io`.
2. Upload `index.html`, `styles.css`, `script.js` (and this README).
3. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/root`.
4. After a minute it's live at https://dipeshadhi.github.io/
