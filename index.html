01

Sprintcal — a Jira × calendar hybrid

Private preview

Every team I've coordinated had the same split: tasks live in Jira or Trello, time lives in Google Calendar, and nobody can see whether the sprint actually fits in the week. Sprintcal puts sprint tickets straight onto a calendar so story points turn into time blocks you can see clash.

  • Drag a ticket onto the week → it becomes a time block
  • Over-committed days go red before standup, not after the retro
  • Board, calendar and a mixed view of the same data

The prototype runs on Vercel behind a password while I test it with a few pilot teams. I'm not posting the link publicly yet; happy to walk you through it.

04

MSc thesis — routing support tickets with a small LLM + RL

Code not public yet

An AI helpdesk that listens to a customer, works out intent and mood, scores priority, and lets two Q-learning agents decide which department gets the ticket. Everything runs locally on an Ollama-hosted small language model, so no customer audio leaves the building. Admins can overrule the routing, and every correction is fed back as a reward signal.

inputVoice / text
→
ASRWhisper
→
SLM · OllamaIntent + sentiment
→
scoringPriority
→
dual Q-learningDept. + queue
↺ admin correction → reward

What I measured

Routing accuracy, CSAT and speed-to-resolution, with tier-based data contracts between each stage.

Why local

Privacy, latency and cost. A hosted LLM per call doesn't make sense for a small support desk.

Stack

Django full-stack, Whisper, Ollama, scikit-learn sentiment, custom Q-learning agents, observable routing log.

Repo & demo

Private until the dissertation is through marking. Ask and I'll screen-share it.
